# SKORBININ CRIME CITY 11.0 — GitHub Pages

Ready-to-publish static game, single-file build.

## Installation
1. Create a PUBLIC repository at https://github.com/new e.g. `crime-city`.
2. Extract ZIP. Upload `index.html` and `.nojekyll` to the repository root, commit.
3. In repo Settings -> Pages choose Deploy from a branch, branch `main`, folder `/(root)`, Save.
4. Open Pages URL from Settings -> Pages.

## Updating
Replace root `index.html`, commit.

## Progress
Game uses browser localStorage; the new github.io origin cannot automatically read save data from Netlify. Don't delete the old site or clear Safari website data.
